# Data-Challenge-2026 - Data Mining
Individual project for the Data Mining exam. The project is structured like a [Kaggle](https://www.kaggle.com/t/732bf4fb7b6c4cc2944a86844c299335) competition.

## About the data
The dataset consists of information from 30524 Indian women. For roughly 21000 of these
women you know whether they use contraception, denoted as contraceptive, along with
additional input variables describing their socio-demographic characteristics. For the
remaining roughly 9500 women, you have only information on the inputs and not on their
contraceptive use.

The **goal** is to predict contraceptive for the held-out women.

In addition to the version provided for the exam, an enriched version of the dataset, 
generated by me, is available, which includes some socioeconomic variables for Indian regions.
The variables are available from the [Reserve Bank of India's Handbook of Statistics on Indian States](https://www.rbi.org.in/Scripts/PublicationsView.aspx?id=23458).
